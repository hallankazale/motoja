# MotoJá

Protótipo responsivo de um aplicativo de corridas de moto, criado para validar a experiência do passageiro antes da implementação de backend, pagamentos e rastreamento real.

## Funcionalidades da demonstração

- Origem e destino.
- Atalhos de locais.
- Estimativa simulada de preço.
- Busca de motociclista.
- Perfil, moto, placa e código de segurança.
- Início e encerramento da corrida.
- Avaliação do motociclista.
- Layout otimizado para celular.

## Como testar

Abra o arquivo `index.html` no navegador ou publique a branch `main` pelo GitHub Pages.

No GitHub: **Settings → Pages → Deploy from a branch → main → /root → Save**.

Depois, o endereço normalmente será:

`https://hallankazale.github.io/motoja/`

## Limites desta versão

Esta versão usa dados fictícios. Não possui autenticação, GPS real, banco de dados, pagamentos, verificação de documentos ou comunicação com motociclistas.
